# Code of Conduct

Participants in AgentProof are expected to be respectful, constructive, and precise. Discussions should focus on evidence, reproducibility, security, and user impact. Harassment, discrimination, threats, doxxing, and intentionally disruptive behavior are not acceptable.

Maintainers may remove comments, close issues, or restrict participation when behavior violates this standard. Security reports should follow `SECURITY.md` rather than being disclosed in a public issue.
